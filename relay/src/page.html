MyTV – Contrôle à distance

Sur la TV du client : Réglages → Support → Code d'accès (ou « Aide à distance » sur l'écran d'ajout de portail). Il te donne le code affiché.

Tout est chiffré de bout en bout avec le code : le relais ne transporte que des données illisibles et ne garde rien.

Connexion… Clavier : flèches, Entrée OK, Échap retour, chiffres
